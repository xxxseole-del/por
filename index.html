活动视觉

大宝山 · KV 视觉设计

活动视觉 · Event Visual

项目背景

本项目为企业大学生应届毕业生入职活动视觉设计，围绕“矿启新程，圆梦宝山”主题，结合企业IP形象与活动标语，完成主视觉KV及系列活动物料的视觉设计与延展，建立统一的活动视觉形象。

设计思路

以“矿启新程，圆梦宝山”为核心主题，针对大学生应届生群体提取“青春、活力、阳光、能量”作为视觉关键词。通过明快的色彩、富有动感的图形与轻松活跃的版式，营造积极向上的入职氛围。将企业IP形象与企业文化理念“广聚天下英才，晟启美好未来”标语融入主视觉，在强化企业品牌识别的同时，赋予整体视觉更年轻、亲和的表达。

元素介绍

蓝天白云 / 城市建筑 / 道路 / 纸飞机 / 热气球 / 企业IP / 矿业元素

色彩方案

蓝色主调 / 黄橙点缀 / 白色辅助 / 多彩渐变

包装设计

三福系列

项目背景

三福"定格万千生活"主题系列包装设计

设计说明

通过独特的视觉语言与创新的包装形式，把三福原本的正方形方格改变成涂鸦风的飞溅液体，人物以卡通互动风格，体现包装涂鸦的趣味性和互动性，提升包装的视觉效果。色彩搭配保留了三福原本的色彩，并且将 logo 也搭配成彩色，在统一的风格中展现产品色彩的多样性。将三福品牌"发现生活之美"的理念具象化，以包装为载体捕捉美好瞬间，让消费者在使用产品时，能感受到生活的丰富多彩与品牌的温度。

超能系列

项目背景

超能洗衣液"生态科技，让运动更美好"主题系列

设计说明

作品使用品牌蓝绿、玫红标准色，以动感运动插画表现运动场景，可视化呈现污渍隔离、根源去汗臭、72 小时长效抑菌、保护运动面料机能等核心功效。包装与海报视觉体系统一，面向泛运动年轻群体，传递运动专洗的消费观念。整套设计具备品类延展性，兼顾货架辨识度与线上传播效果，塑造青春专业的运动洗护品牌形象。
